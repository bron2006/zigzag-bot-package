# Уточнення масштабу та повний quote replay

Після M5-результатів, ДО повного tick replay. Вибір параметрів не оптимізується.
Діагностичне перемасштабування logged LIMIT/SL ВІДХИЛЕНО як неправильне:
буквальні ціни в логах відповідають протокольній історії. ctrader._on_symbols_loaded
кладе LightSymbol без digits у cache; resolve_price_divisor тоді бере fallback5.
Отже, наявність /10**digits у функції не доводить 100x помилки у цих логах.
Це виправлення інтерпретації, не вибір прибуткового масштабу. Протокол і
числа додаткового M5-діагностичного сценарію збережено для аудиту, не як
валідний результат стратегії. Основний literal M5-сценарій незмінний.

378 first pair-day намірів, ті самі LIMIT/SL, timezone й session end.
Фактичні quote streams ASK/BID від timestamp-60s до 16:00 UTC,
зворотна пагінація за hasMore. Секундні стінні timestamps втратили ms
логів: виконання не раніше timestamp+1s. Тому це paper-апроксимація
латентності, не виконання брокерського ордера.

Первинний fill: перший ASK<=LIMIT після timestamp+1s. Виконання
консервативно рівно LIMIT, без price improvement. Після fill використовуємо
BID<=SL: вихід за фактичним BID (gap/slippage можливі). VWAP-target
тримати відомим із останнього завершеного M5 бару та перевіряти BID>=target,
лише target>LIMIT. Вихід за target без позитивного ковзання. Це причинний
resting-target paper-варіант, НЕ live exit MARKET після 60s polling.
SL перевіряти першим. Exit16:00 за останнім BID, якщо quote не старший60s.
При одночасних ticks порядок невідомий: SL-first. Неповна історія/відсутня
ASK/BID/price quote для кінця — unavailable, не угода з нульовим PnL.

Спред уже присутній у ASK/BID, не віднімати його повторно. Комісія
0.02*ATR14 за повний цикл, стрес0.04*ATR14 та додаткове негативне
exit slippage0.02*ATR14. ATR відомий до log timestamp. Це комісійні й
execution припущення, не фактичний тариф/черга виконання брокера.
Комісію в грошах/рахунок/portfolio risk-manager не моделювати.

Денний bootstrap і періоди як у M5-протоколі. Усі missing/failed включити
в counts; PnL обчислювати лише де шлях визначений. Зберегти raw quote
pages або lossless декодовані time/price streams, параметри, checksums.
Три попередні короткі quote-вікна — лише QA, не валідація всієї вибірки.
