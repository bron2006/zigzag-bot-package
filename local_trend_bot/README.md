# Локальний дослідницький бот

Окремий від VWAP. Лише публічні ціни Binance, жодних ключів, Supabase,
cTrader, Telegram, AI-рішень або API для реальних ордерів. Python stdlib.

Дві фіксовані стратегії: денний пробій55/вихід20 та momentum365.
BTC/ETH, long або cash, без плеча. На кожне правило окремий віртуальний
рахунок1000USDT:500BTC-кошик+500ETH-кошик. НЕ складати ці рахунки як
дохід одного депозиту. Початкові500 — cash, не вже придбані монети.

Ретроспективна перевірка з незмінними правилами завершена.

Це доходність ЗА ВЕСЬ ПЕРІОД, не місяць і не обіцянка. ОБИДВА правила
НЕ пройшли заздалегідь записаний gate: bootstrap-перевага над matched
hold не доведена, частина DD завелика. Повний результат
research_result_v1.json; метод PROTOCOL.md. Нові дані потрібні для
діагностики, не для оголошення відхиленої моделі прибутковою.

Режим за замовчуванням тільки записує сигнали. --diagnostic-paper
вмикає саме експериментальні віртуальні угоди відхилених моделей.
Перший день bootstrap без входів; наступні UTC-дні — за попередньо
відомими сигналами з однією повною добою затримки. Раз на15хв перевірка
цін, максимум одна обробка рішення rule/symbol/day. Long утримується
до exit-сигналу, вихідні для крипти не є зупинкою.

Live-paper входить за спостереженим ASK, виходить за BID, додаткові
витрати0.3%/сторону. Історичний Open — проксі, не тотожна live-ціна:
пізній запуск, затримка/DNS та відмінності джерела лишаються ризиком.
Пропущені дні записуються, минулі угоди не відновлюються вигаданими
цінами. Нетто-оцінка відкритого кошика — BID мінус exit-fee.

Журнал logs/local_trend_bot.sqlite3: книги, рішення, угоди, health.
Single-writer OS-lock; SQLite WAL, зміни двох активів атомарні.
Whole fetch-child timeout45s. Stale/invalid/gap history: нуль нових
угод, видима last_error, наступна безпечна повторна спроба через15хв.
Процес сам не переживе reboot Windows: Task Scheduler не реєстрували.

Команди з кореня проєкту:

`python -m local_trend_bot.bot --status`

`python -m local_trend_bot.bot --loop --diagnostic-paper`

Не стартувати другий loop поверх чинного; lock відмовить.
22 тести: причинність, затримка, незалежна звірка equity, комісії,
ASK/BID, bootstrap, дублі/restart, stale inputs, атомарність,
single-writer та відсутність приватного API.
